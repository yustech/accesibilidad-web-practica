# Reto final del portal de formación

## Contexto

El portal permite filtrar cursos, guardar como favorito el curso de HTML accesible y solicitar una plaza. El filtro modifica el catálogo; la ficha seleccionada permanece identificada explícitamente como HTML. La solicitud es una demostración local y no transmite información.

Dispones de 70 minutos. Antes de consultar la solución, registra tres barreras y acuerda su prioridad con tu pareja. Si no completas todas las correcciones, entrega lo verificado y un backlog que explique lo pendiente.

## Tareas de usuario

1. Encontrar cursos online y saber cuántos quedan.
2. Guardar o quitar de favoritos el curso de HTML utilizando teclado.
3. Abrir la inscripción, enviar vacía y comprender cómo corregir errores.
4. Completar nombre y correo ficticios, enviar y volver al punto de partida.

## Entrega

- Código modificado desde [inicio](inicio/index.html).
- Tres incidencias con impacto y criterio WCAG justificado.
- Evidencias de teclado, una prueba con lector y resultados de automatización.
- Dos criterios de aceptación para evitar regresiones.
- Un pequeño plan de equipo con responsable, prioridad y revisión.

Usa [la rúbrica](../plantillas/rubrica.md) y [la plantilla](../plantillas/incidencia.md). La [solución de referencia](solucion/index.html) integra patrones de las prácticas y permite recuperar el ritmo. No representa una aplicación de matrícula de producción.

## Comprobaciones mínimas

- El filtro no pierde foco y el recuento se comunica.
- El favorito responde a Enter y Espacio y comunica su estado.
- El diálogo tiene nombre, entrada de foco y cierre con retorno.
- Los errores se asocian a campos y permiten corregir manteniendo los datos.
- La presentación no pierde controles a 320 píxeles CSS.
- Cada afirmación del informe indica cómo se ha comprobado o que queda pendiente.

## Plan de accesibilidad

Después del reto, utiliza los 25 minutos de implantación para completar [la plantilla de plan](../plantillas/plan-accesibilidad.md), apoyándote en [el ejemplo resuelto](../docs/plan-accesibilidad-ejemplo.md). Traslada tres incidencias a acciones con responsable, recursos, plazo y evidencia. Añade dos indicadores y una próxima revisión. El plan se entrega junto al código, las incidencias y los dos criterios de aceptación.
