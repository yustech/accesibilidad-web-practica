# Criterios de aceptación

## Historia

Como persona que utiliza teclado, quiero completar la inscripción para reservar una plaza.

## Condiciones verificables

1. Al abrir el diálogo con Enter, el foco entra en él y su título permite identificar la tarea.
2. Al enviarlo vacío, el resumen permite localizar y corregir cada campo con error.
3. Al cerrar con Escape o Cancelar, el foco vuelve al disparador disponible.
4. Con una ventana de 320 píxeles CSS de ancho no se pierde el acceso a campos y botones.

## Evidencia y revisión

Anota entorno, pasos, resultado y responsable. Relaciona cada condición con el criterio que realmente evalúa. Añade una prueba automática si protege comportamiento relevante y una revisión manual cuando sea necesaria.
