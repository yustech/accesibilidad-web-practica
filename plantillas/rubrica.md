# Rúbrica del reto final

| Dimensión                  | Peso | Evidencia suficiente                                                          |
| -------------------------- | ---- | ----------------------------------------------------------------------------- |
| Corrección y funcionalidad | 35 % | La tarea se completa, semántica y estados coinciden, sin regresiones.         |
| Prueba manual              | 25 % | Recorrido de teclado y prueba con lector registrados con entorno y resultado. |
| Interpretación WCAG        | 20 % | Al menos tres criterios bien justificados, sin confundir nivel con severidad. |
| Documentación y prevención | 20 % | Incidencias reproducibles, prioridad y dos criterios de aceptación.           |

Cada dimensión se puntúa de 0 a 4: 0 sin evidencia, 1 incompleta, 2 básica con errores relevantes, 3 suficiente y verificable, 4 precisa con casos alternativos. Puntuación total: suma de peso × puntuación / 4.

Un bloqueo de teclado en la tarea principal requiere revisión de la entrega aunque el total sea alto. La rúbrica mide aprendizaje y no certifica conformidad de una web.
